# 快捷键

## 文件

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+O` | 打开文件 |
| `Ctrl+Shift+O` | 打开文件夹 |
| `Ctrl+S` | 保存 |
| `Ctrl+W` | 关闭当前文档 |

## 视图

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+1` | 源码 |
| `Ctrl+2` | 分栏 |
| `Ctrl+3` | 预览 |
| `Ctrl+\` | 显示/隐藏侧栏 |

## 编辑

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+B` | 加粗 |
| `Ctrl+I` | 斜体 |
| `Ctrl+K` | 插入链接 |
| `Ctrl+Shift+T` | 插入表格 |
| `Ctrl+F` | 查找 / 替换 |
| `Ctrl+Shift+F` | 跨文件搜索 |
