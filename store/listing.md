## 详细描述（≤ 10000 字符）

```
AuditNote 是一个"打开即用"的 Markdown 阅读与编辑器。它不要求你先建库、先登录、先选文件夹——
双击一个 .md 文件，窗口就是那篇文章；新建一个空白页，直接开始写。

【三种视图，随时切换】
· 源码：纯文本编辑，行号、语法着色、自动换行
· 分栏：左边写、右边即时预览，中间竖条可拖动调比例
· 预览：沉浸阅读

【两边都能改】
分栏视图下，直接点预览里的段落就能改字——不是弹窗、不是富文本，
改的就是 Markdown 源码本身，左侧同步更新，撤销历史照样能用。

【该有的都有】
· GFM：表格、任务列表、删除线、脚注
· 代码高亮（40+ 语言）、KaTeX 公式、Mermaid 图表
· 画布式流程图：拖节点、从四边端口拉线、判断分支、自动排布，生成标准 Mermaid 代码
· 跨文件全文搜索：打开一个文件夹，按内容或文件名检索
· 导出 HTML（单文件可离线打开）与 PDF（走系统打印引擎，中文零风险）
· 深色 / 浅色 / 护眼三套主题，字号行距可调

【本地优先】
完全离线运行，不联网、不建库、不上传任何内容。你的文件留在你自己的磁盘上，
应用只读写你打开的那个文件，以及自己的一份索引库（用于搜索，可随时删除）。

【为 Windows 而做】
安装后接管 .md 关联，右键菜单里直接「新建 → Markdown 文档」；
支持双击文件启动、单实例（不会开两个窗口抢写同一个文件）。
```

## 认证注意事项（会被 WACK 检查）

| 检查项 | 本项目的做法 |
| --- | --- |
| 不要求管理员权限 | 打包为 FullTrust + `currentUser`，安装与运行都不提权 |
| 安装到用户范围、可干净卸载 | MSIX 由系统管理；NSIS 装到 `%LOCALAPPDATA%`，卸载时清理注册表钩子 |
| 文件关联必须走清单声明 | MSIX 用 `windows.fileTypeAssociation`（见 `src-tauri/msix/AppxManifest.xml`） |
| 启动 5 秒内出现可交互窗口 | 冷启动实测约 1 秒（含 WebView2 冷启动） |
| 无隐藏网络通信 | 应用代码里没有任何 fetch / 上报，离线可完整运行 |
| 不使用已弃用的 API | 基于 Tauri 2 + WebView2，无 IE 依赖 |
